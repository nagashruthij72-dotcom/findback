# FindBack – AI Lost & Found Platform

FindBack is an AI-powered Lost & Found platform that helps users find their lost belongings by intelligently matching lost and found item reports.

## Features

- Report lost items
- Report found items
- AI-based text similarity matching
- AI-based image similarity matching
- Match score and match level
- User registration and login
- Personal lost/found reports
- Match notifications
- Search and filter items
- Responsive and modern web interface

## AI Technology

FindBack uses:

- **TF-IDF + Cosine Similarity** for text matching
- **ResNet18** for image feature extraction and image similarity
- **Flask** for the web application
- **SQLite** for database management

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Scikit-learn
- PyTorch
- Torchvision

## How It Works

1. A user reports a lost item.
2. Another user reports a found item.
3. FindBack compares the item details using AI.
4. Text and image similarities are combined.
5. If a strong match is detected, the owner receives a notification.

## Project Goal

The goal of FindBack is to make the lost-and-found process faster, easier, and more intelligent using AI.
